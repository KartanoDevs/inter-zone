Ventana de Cuenta

Tres direcciones sobre el sistema de diseño real de InterZone (tokens de src/styles.css y docs/voley/design-guidelines.md): fondo oscuro, Orbitron/Inter, botones facetados, neón como puntuación. Dos vistas —Datos usuario / Logros— con un segmented control. Solo mockups estáticos.

1 · HUD Consola

Segmented control de dos pestañas facetadas (firma clip-path de la app). Logros como lista vertical de filas: chip con sigla, nombre, fecha y estado. Verde = superado, ámbar = pendiente. Denso, técnico, un solo glow (pestaña activa).

Abrir diseño 1

2 · Placas

Segmented control tipo píldora con relleno cian translúcido (mismo lenguaje que el badge de rol). Logros como rejilla de 3 placas circulares: anillo verde + check en las conseguidas, contorno discontinuo + candado en las bloqueadas. Aireado.

Abrir diseño 2

3 · Mosaico + medallas  ← elegido

Base elegida, ya evolucionada. Segmented control con barra-indicador deslizante. Logros = mosaico con una pieza por sistema; cada pieza lleva las 3 ranuras de medalla (bronce/plata/oro, PNG reales de public/medals/) encendidas o apagadas. Al tocar una pieza se abre un panel con el desglose por titular (C, R1, R2, C1, C2, O, L). Contador = sistemas con oro / total.

Estado: elegido el Diseño 3 y evolucionado con el sistema real de medallas (dominio insignias.ts / examen.ts):
  • Por sistema puedes ganar bronce (examen por puesto), plata (por línea) y oro (sistema completo). Bronce y plata van por titular, así que un sistema puede acumular varios (bronce de C1 + bronce de R1…).
  • Cada pieza del mosaico muestra las 3 ranuras de medalla con las PNG de public/medals/; apagadas si no conseguidas. Pieza en cian sólido = sistema dominado (tiene oro).
  • Tocar una pieza abre el panel de detalle: fila por tier con la medalla grande y los puestos ganados como chips (C1, R1…), o "Sin examinar / Pendiente".
  • Contador: 2 / 9 sistemas dominados (los que tienen oro).
  • Datos de ejemplo inventados (9 sistemas); el catálogo real es dinámico por equipo.
